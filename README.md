# 💖 My Anniversary

เว็บไซต์แสดงความทรงจำและเนื้อหาเฉลิมฉลองวันครบรอบ พัฒนาด้วย React, TypeScript และ Vite พร้อมตกแต่งส่วนติดต่อผู้ใช้ด้วย Tailwind CSS

## 1. ข้อกำหนดเบื้องต้น

ก่อนเริ่มต้นใช้งาน โปรดตรวจสอบว่าเครื่องคอมพิวเตอร์ของคุณติดตั้งซอฟต์แวร์เหล่านี้แล้ว:

- Node.js (รุ่นที่รองรับการทำงานกับ dependencies ใน package.json)
- npm (ติดตั้งมาพร้อมกับ Node.js)
- เว็บเบราว์เซอร์สมัยใหม่ เช่น Google Chrome, Microsoft Edge หรือ Firefox

คุณสามารถตรวจสอบเวอร์ชันที่ติดตั้งในเครื่องได้โดยการรันคำสั่งนี้ใน PowerShell:

```powershell
node --version
npm --version
```

## 2. การติดตั้งโปรเจกต์

เปิดโปรแกรม PowerShell แล้วเข้าไปยังโฟลเดอร์โปรเจกต์ของคุณ:

```powershell
cd "C:\Users\67143\Desktop\lovegorpor\my-anniversary"
```

ติดตั้งแพ็กเกจ dependencies ทั้งหมด:

```powershell
npm install
```

> **คำแนะนำ:** หากมีไฟล์ `package-lock.json` อยู่แล้ว แนะนำให้ใช้คำสั่งนี้เพื่อให้ได้เวอร์ชันของ dependencies ที่ตรงกันอย่างแม่นยำ:

```powershell
npm ci
```

## 3. การเปิดเว็บไซต์ระหว่างพัฒนา

เริ่มต้นใช้งานเซิร์ฟเวอร์สำหรับพัฒนา (Development Server):

```powershell
npm run dev
```

หลังจากรันคำสั่งแล้ว ให้เปิด URL ที่แสดงขึ้นมาในหน้าต่าง PowerShell (โดยทั่วไปคือ):
`http://localhost:5173`

- ระบบรองรับ **Hot Module Replacement (HMR)** เมื่อคุณแก้ไขไฟล์ซอร์สโค้ด เว็บไซต์จะทำการรีเฟรชการเปลี่ยนแปลงให้อัตโนมัติทันที
- หากต้องการหยุดการทำงานของเซิร์ฟเวอร์ ให้กดปุ่ม `Ctrl + C` ใน PowerShell

## 4. คำสั่งที่ใช้งานได้

สรุปคำสั่งสำคัญที่ใช้งานผ่าน `package.json`:

| คำสั่ง | รายละเอียด |
| :--- | :--- |
| `npm install` | ติดตั้ง dependencies ทั้งหมดของโปรเจกต์ |
| `npm ci` | ติดตั้ง dependencies ตาม `package-lock.json` อย่างสะอาด |
| `npm run dev` | เปิดเซิร์ฟเวอร์สำหรับพัฒนาในเครื่อง |
| `npm run lint` | ตรวจสอบรูปแบบและค้นหาข้อผิดพลาดตามกฎ ESLint |
| `npm run build` | ตรวจสอบ TypeScript และสร้างไฟล์ Production ในโฟลเดอร์ `dist` |
| `npm run preview` | เปิดดูตัวอย่างไฟล์ Production ที่ Build แล้วในเครื่อง |

## 6. การอัปเดตเว็บไซต์ผ่าน Netlify Drop

วิธีนี้เหมาะสำหรับการเผยแพร่เว็บไซต์แบบ Static โดยไม่ต้องติดตั้ง Netlify CLI หรือเชื่อมต่อ Git repository ให้ยุ่งยาก

### 6.1 สร้างไฟล์ Production

ทุกครั้งที่มีการแก้ไขเว็บไซต์ ให้เปิด PowerShell ที่โฟลเดอร์โปรเจกต์แล้วรันคำสั่ง:

```powershell
cd "C:\Users\67143\Desktop\lovegorpor\my-anniversary"
npm run build
```

> ⚠️ **ข้อควรระวัง:** ห้ามลากโฟลเดอร์โปรเจกต์ทั้งหมดขึ้น Netlify ให้ใช้เฉพาะโฟลเดอร์ `dist` ที่เพิ่งถูกสร้างขึ้นมาใหม่เท่านั้น

### 6.2 อัปโหลดเว็บไซต์ครั้งแรก

1. เปิดเว็บไซต์ [Netlify Drop](https://app.netlify.com/drop)
2. เปิด File Explorer ไปที่โฟลเดอร์โปรเจกต์ แล้วเลือกโฟลเดอร์ `dist`
3. ลากโฟลเดอร์ `dist` ไปวางในพื้นที่อัปโหลดของ Netlify
4. รอจนกว่า Netlify จะประมวลผลและอัปโหลดเสร็จสิ้น
5. คลิกเปิด URL ที่ Netlify กำหนดให้เพื่อทดสอบเว็บไซต์

### 6.3 การอัปเดตเว็บไซต์เดิม

เมื่อมีการเปลี่ยนแปลงเนื้อหาหรือโค้ด:

1. แก้ไขไฟล์ในโฟลเดอร์ `src` หรือ `public` ตามต้องการ
2. รันคำสั่ง `npm run lint` เพื่อเช็คความเรียบร้อย
3. รันคำสั่ง `npm run build` เพื่อสร้างโฟลเดอร์ `dist` ใหม่
4. ลากโฟลเดอร์ `dist` ใหม่ไปวางทับบนหน้าแดชบอร์ดเว็บไซต์เดิมใน Netlify
5. ตรวจสอบหน้าแรก รูปภาพ ปุ่ม และเนื้อหาสำคัญบน URL จริง

## 7. โครงสร้างโฟลเดอร์สำคัญ

โครงสร้างภายในโปรเจกต์ `my-anniversary` มีการจัดระเบียบดังนี้:

```text
my-anniversary/
├─ public/              # ไฟล์ Static และรูปภาพที่เข้าถึงได้โดยตรง
├─ src/                 # ซอร์สโค้ด React และ TypeScript
│  ├─ assets/           # ไฟล์ประกอบที่ Import ผ่านซอร์สโค้ด
│  ├─ data/             # ข้อมูลและเนื้อหาที่ใช้แสดงผลในเว็บไซต์
│  ├─ editpic/          # ส่วนจัดการหรือแก้ไขรูปภาพ
│  ├─ App.tsx           # คอมโพเนนต์หลักของแอปพลิเคชัน
│  ├─ App.css           # สไตล์หลักเพิ่มเติมของแอปพลิเคชัน
│  ├─ index.css         # สไตล์พื้นฐานระดับ Global (Tailwind)
│  └─ main.tsx          # จุดเริ่มต้นการ Render ของ React
├─ dist/                # ไฟล์ Production ที่สร้างขึ้นจากคำสั่ง build
├─ index.html           # HTML Entry Point
├─ package.json         # รายชื่อ Scripts และ Dependencies
├─ package-lock.json    # ล็อกเวอร์ชันของ Dependencies
├─ vite.config.ts       # การตั้งค่า Vite และ Development Plugins
└─ tsconfig*.json       # การตั้งค่า TypeScript
```

## 8. การจัดการรูปภาพและข้อจำกัด

รูปภาพที่ต้องการให้แสดงผลบนเว็บไซต์ ควรจัดเก็บไว้ภายในโฟลเดอร์ `public` หรือในตำแหน่งที่ซอร์สโค้ดสามารถ Import เข้ามาใช้งานได้อย่างถูกต้อง

ทุกครั้งที่มีการเพิ่มหรือลบรูปภาพ แนะนำให้ทำการ Build ใหม่เสมอ:

```powershell
npm run build
```

จากนั้นนำโฟลเดอร์ `dist` ล่าสุดอัปโหลดขึ้น Netlify Drop

### 📌 ข้อจำกัดของการอัปโหลดรูปภาพบน Netlify Drop

ในโหมดพัฒนา (Development) โปรเจกต์นี้มี Vite Endpoint แบบจำลอง (`/api/pictures`) สำหรับช่วยอ่านรายชื่อและอัปโหลดรูปภาพเข้าสู่โฟลเดอร์ `public/picture` ได้ แต่เนื่องจาก Netlify Drop เป็นการโฮสต์แบบ Static เว็บไซต์จึงไม่มี Backend Server มารองรับฟังก์ชันนี้ ส่งผลให้:

- การแสดงรูปภาพ Static ที่อยู่ในโฟลเดอร์ `public` ตั้งแต่ต้นจะทำงานได้ปกติ
- ปุ่มอัปโหลดรูปภาพใหม่จากหน้าเว็บจริงอาจไม่สามารถบันทึกไฟล์ถาวรบน Netlify Drop ได้
- หากต้องการระบบอัปโหลดรูปภาพจริงบน Production แนะนำให้เปลี่ยน Endpoint ไปใช้ **Netlify Functions** หรือบริการฝากไฟล์ภายนอก (เช่น Cloudinary หรือ Supabase Storage)

## 9. การแก้ไขปัญหาเบื้องต้น (Troubleshooting)

### ❓ คำสั่ง `npm` ไม่พบ
- **วิธีแก้:** ติดตั้ง Node.js ใหม่จาก [เว็บไซต์ทางการของ Node.js](https://nodejs.org/) แล้วเปิดหน้าต่าง PowerShell ใหม่

### ❓ ปัญหาเกี่ยวกับ Dependencies
- **วิธีแก้:** ลบโฟลเดอร์ `node_modules` เดิมทิ้ง แล้วทำการติดตั้งใหม่แบบสะอาด:
  ```powershell
  Remove-Item -Recurse -Force "node_modules"
  npm ci
  ```

### ❓ Build ไม่สำเร็จ
- **วิธีแก้:** ตรวจสอบตามลำดับขั้นตอนนี้:
  1. อ่านข้อความ Error สีแดงในหน้า PowerShell เพื่อดูว่าเกิดจากไฟล์ไหน
  2. รัน `npm run lint` เพื่อตรวจหาข้อผิดพลาดทางไวยากรณ์
  3. ตรวจสอบการ Import ไฟล์ที่เพิ่งแก้ไขล่าสุด
  4. ลองรัน `npm ci` เพื่อให้แน่ใจว่าติดตั้ง Dependencies ครบถ้วน
  5. รันคำสั่งย้ายโฟลเดอร์และ Build ใหม่อีกครั้ง:
     ```powershell
     cd "C:\Users\67143\Desktop\lovegorpor\my-anniversary"
     npm run build
     ```

### ❓ เปิดเว็บแล้วเจอหน้าเก่าหรือไฟล์ไม่ครบ
- **วิธีแก้:** ตรวจสอบว่าคุณได้ทำการ Build ใหม่หลังแก้ไขโค้ดแล้วหรือไม่, ตรวจสอบว่าลากโฟลเดอร์ `dist` ล่าสุด (ไม่ใช่โฟลเดอร์เก่า), และลองกดรีเฟรชแบบล้างแคช (`Ctrl + F5`) หรือเปิดในโหมด Incognito

## 10. แนวทางการทำงานที่แนะนำ

1. แก้ไขซอร์สโค้ดในโฟลเดอร์ `src` หรือเพิ่มไฟล์ใน `public`
2. รัน `npm run dev` เพื่อดูผลลัพธ์และทดสอบระหว่างพัฒนา
3. ตรวจสอบความถูกต้องด้วย `npm run lint`
4. สร้าง Production Build ด้วย `npm run build`
5. ทดสอบไฟล์ที่สร้างขึ้นด้วย `npm run preview`
6. นำโฟลเดอร์ `dist` อัปโหลดขึ้น Netlify Drop
7. ตรวจสอบความเรียบร้อยบนเว็บไซต์จริงหลัง Deploy ทุกครั้ง
